# Security Policy

## Supported versions

PnPLab is pre-1.0. Security fixes land on the default branch (`develop`) and
ship in the next tagged release.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

1. Prefer a private [GitHub security advisory](https://github.com/aukilabs/pnp-lab/security/advisories/new).
2. Or email [dev@aukilabs.com](mailto:dev@aukilabs.com) with the subject
   `PnPLab security`.

Include enough detail to reproduce the issue (affected API, inputs, and
expected vs actual behavior). We will acknowledge receipt and follow up with a
timeline once the report is triaged.
